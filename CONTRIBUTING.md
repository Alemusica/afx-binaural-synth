
# Contribuire

1. Discuti la feature aprendo una Issue.
2. Crea una branch `feature/<nome>`.
3. Aggiungi test e documentazione.
4. Assicurati che CI passi su macOS.
5. Apri una Pull Request.

## Stile
- C++17, clang-format (Google style, 120c).
- Nomi file PascalCase per classi, snake_case per funzioni free.

## Commits
- Tipo: `feat:`, `fix:`, `docs:`, `refactor:`, `perf:`, `test:`.
